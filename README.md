# New Leaf Microgreens

A simple static website designed for Cloudflare Pages.

## Publish with Cloudflare Pages

1. Create a new GitHub repository and upload these files to its main branch.
2. In Cloudflare, open **Workers & Pages** → **Create application** → **Pages** → **Connect to Git**.
3. Select the repository.
4. Choose **No framework**. Leave build command blank and set the output directory to `/`.
5. Deploy, then use **Custom domains** in the Pages project to connect the domain you bought through Cloudflare.

The order buttons currently call `519-778-8158`, so customers can reach you directly. Replace them with an online checkout link whenever you are ready to accept card payments online.
